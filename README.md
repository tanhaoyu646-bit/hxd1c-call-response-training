# HXD1C两站一区间确认呼唤（应答）训练

本项目从验收后的“途中瞭望技巧”基座完整复制后独立建立。项目目录、训练状态与发布配置相互独立，当前修改不会写回“途中瞭望技巧”或其他训练项目。

## 入口

- `/`：独立项目首页。
- `/call-response-training/?mode=teaching`：教学模式。
- `/call-response-training/?mode=assessment`：考评模式。

## 训练规则

- 两站一区间共19个呼唤点：发车前出站信号和联控发车状态、起动后开车时刻、2.0级后部瞭望、出站信号机处对标、仪表确认、列尾查询、过分相、5架区间通过信号、进站前车位及列尾确认、进站信号和越过进站信号时的车位确认。
- 总分100分，错答、漏答均不得分，不倒扣。
- 每个呼唤点均衡随机抽取“操纵司机”或“非操纵司机”内容，学生选择一个完整呼唤（应答）选项。
- 教学模式到点自动切回正面驾驶台、冻结运行并弹出操作台中央面板。错答本题0分，显示标准内容并播放完整语音后继续运行。
- 考评模式不冻结运行。学生须在有效区间内点击对应信号机、过分相线路标志或驾驶台设备，再用中央缩小面板答题；错答或漏答本题0分。
- 每题结束均播放“非操纵司机呼唤—操纵司机应答—非操纵司机复诵”的完整语音序列。

当前标准文本由项目配置集中维护。正式交付前，应按项目指定版本的《铁路机车操作规则》和评分表逐项签认。

